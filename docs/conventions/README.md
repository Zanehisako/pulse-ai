# Conventions du Projet

## Objectif
Standardiser la contribution (Web, Mobile, API, IA/ML, Infra/Data) : **naming**, **commits**, **branches**, **API**, **workflow PR**.

## Fichiers
- Naming : `naming-conventions.md`
- Commits : `commit-conventions.md`
- Branches : `branch-conventions.md`
- API : `api-conventions.md`

## Règles clés
- Code en **anglais**, documentation en **français**
- PR obligatoire, **2 approvals**, CI OK
- Commits atomiques, branches normalisées

## En cas de conflit
La règle la plus stricte gagne (sécurité, qualité, CI).
